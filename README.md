# Logistics Data Analyst – Week 4

## Predictive Modeling and Optimization in Logistics using Python

This project is part of the Yuva Intern Logistics Data Analyst Internship – Week 4 task.

### Objective
Build a predictive model for a logistics metric and translate model insights into operational optimization recommendations.

### Target
`Delivery_Time_Days`

### Models
- Linear Regression
- Decision Tree Regression
- Random Forest Regression

### Evaluation
- MAE
- RMSE
- R²

### Best model in this simulated experiment
**Linear Regression**
